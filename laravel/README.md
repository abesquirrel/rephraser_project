# Masha AI 🐈‍⬛

**Masha** is an AI-powered rephrasing system designed to transform technical support notes into professional, customer-ready responses.

For full project documentation and architecture, please see the [Root README](../README.md).

## 🛠️ Tech Stack

- **Framework**: Laravel 11
- **Frontend**: Alpine.js & Tailwind CSS
- **AI Backend**: Python (FastAPI/Flask)
- **Vector DB**: FAISS
- **Database**: MariaDB
- **LLM Engine**: Mistral AI API (`open-mistral-nemo`, `mistral-small-latest`, `mistral-tiny`)
